Empat Cara Menyelesaikan SPLDV

Sistem Persamaan Linear Dua Variabel (SPLDV) dapat diselesaikan melalui empat metode utama. Pilih menu di atas atau jelajahi ringkasan metode di bawah ini untuk praktik langsung!

ax + by = c
dx + ey = f
1

Metode Grafik

Menggambar kedua garis pada bidang koordinat. Titik potong garis adalah himpunan penyelesaiannya.

2

Metode Substitusi

Menyatakan satu variabel dalam bentuk variabel lain, lalu memasukkannya ke persamaan kedua.

3

Metode Eliminasi

Menghilangkan salah satu variabel dengan menyamakan koefisiennya untuk mencari nilai variabel lainnya.

4

Metode Campuran

Menggabungkan eliminasi untuk mencari variabel pertama, lalu substitusi untuk variabel kedua.
